# Screenshots Folder

This folder contains UI screenshots for the README.md file.

## Required Screenshots

After running the application, capture the following screenshots:

1. **ui-main.png** - The main interface showing the feedback board status
2. **ui-post.png** - User posting an anonymous message
3. **ui-wallet.png** - Lace wallet connection prompt
4. **ui-view.png** - Viewing posted messages on the board

## How to Capture

1. Run the UI: `cd anon-feed-ui && npm run build:start`
2. Open http://127.0.0.1:8080 in your browser
3. Use your browser's screenshot tool or a tool like Snipping Tool
4. Save screenshots in this folder with the exact names above
5. Update the README.md if filenames differ

## Screenshot Tips

- Use a clean browser window (hide bookmarks bar if distracting)
- Show the full application interface
- Include wallet connection prompts
- Show both empty and occupied board states
- Use consistent sizing (recommended: 1200x800px)
- Consider adding annotations for key features
